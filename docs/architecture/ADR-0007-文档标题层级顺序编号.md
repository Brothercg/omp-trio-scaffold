# ADR-0007 文档标题层级顺序编号

- 状态：accepted
- 日期：2026-10-27
- 关联：ADR-0000（架构总览）
- 决策来源：用户指令（2026-10-27，要求后续文档标题一律带层级顺序编号）

## 1. 上下文

用户要求所有文档的章节标题带层级顺序编号（`1` / `1.1` / `1.2` / `1.2.1`），
便于引用、口头定位与契约指针（如「§3.1」）精确指向。现状：全部文档标题无编号。

## 2. 候选方案

1. 仅约定不编号 —— 引用仍有歧义，不满足诉求。
2. 全部 markdown 标题（H2 起）层级编号 —— 覆盖一致，机械可加。
3. 仅长文档编号 —— 边界模糊（「长」不可判定）。

## 3. 决策

选定 **方案 2**，编号口径：

- **H1 文档标题不编号**（`# ADR-0007 …`、`# 运行手册 …`）；
- **H2 起层级编号**：`## 1. 标题`、`### 1.1 标题`、`#### 1.1.1 标题`；
- 同级顺序递增；上级变动时下级重置（标准文档编号语义）；
- 代码块（fenced code）内的 `#` 注释不参与编号；
- 新文档自撰写时即编号；存量文档分批回填。

**适用范围**：

| 文档类 | 约束 | 执行者 |
|---|---|---|
| `docs/architecture/**`、`docs/task/*/arch-*.md` | 强制（本 ADR 起） | ARCH |
| `README.md`、`docs/RUNBOOK.md` | 强制（本次已回填） | 公共维护区 |
| `docs/task/*/dev-*.md`、`qa-*.md` | 遵循本 ADR | DEV / QA（各自作者） |
| `templates/**` | 模板骨架同规 | 更新需用户落盘（fail-closed） |

## 4. 后果

- 正面：引用可精确定位（「§3.1」）；契约 AC 指针与文档锚点稳定。
- 负面：旧文档内以标题文字互链的锚点可能随编号变化失效，回填时需同步检查。
- 推翻条件：引入自动生成目录（TOC）且与手工编号冲突时，改以 TOC 为准。
