# ADR-0013 交付流程契约：熔断口径、契约粒度与批量终验

- 状态：accepted
- 日期：2026-10-29
- 关联：`ADR-0012`（威胁模型「防呆不防恶」）、`ADR-0011`（策略生效语义）、`docs/RUNBOOK.md`（流程文本待同步 §5）
- 来源：2026-10-29 grill-me 审计（Q3/Q7/Q8/Q9 裁决；威胁模型类归 ADR-0012）

## 1. 上下文

三 agent（ARCH/DEV/QA）流水的吞吐瓶颈与误伤源审计：① 多任务输出缺并行性约定，人工并行无判据；② QA 弱断言（LLM 原生失败模式，非作弊）令「全绿」失真；③ 3 轮熔断不区分失败根因，契约歧义轮会烧穿三屏后停摆；④ 契约粒度无界 + HITL 逐任务等待，人在场率决定吞吐。用户裁决：Q3/Q7/Q8/Q9 全部按推荐采纳。

## 2. 决策

### 2.1 ARCH 多任务输出义务（Q3）
ARCH 输出多个任务时 **MUST** 在契约/分配块中阐明：**可并行性**（哪些任务可并行、哪些互斥）与**前置条件**（任务间依赖、解锁条件）。并行执行由用户自行调度。落点：ARCH 产出模板（spec §分工 / 回复分配块）。

### 2.2 mutation 弱断言质量门（Q7）
定位：**质量门，非防作弊**（威胁模型见 ADR-0012 §2）。对交付 diff 的变异行抽变：QA 用例至少挂一条（变异后不挂 = 断言平凡），报告不得全绿。服务唯一关切维度：大模型落地结果质量。

### 2.3 熔断计数口径（Q8）
- **仅「实现缺陷轮」计入 3 轮熔断**：QA 未通过 → DEV 修 → 复测未通过 = 1 轮，前提是根因判定为实现缺陷。
- 契约缺陷 / QA 用例错 / 环境轮 **不计数**，但 MUST 在 1 轮内转 `contract-gap` / verdict / 用例修正，转不动即 `blocked`（比烧 3 轮快）。
- QA 报告的未通过行 **强制标注根因分类**（实现 / 契约 / 用例 / 环境），无分类不计轮。

### 2.4 契约粒度与批量终验（Q9）
- 契约 **只锁**接口签名 + AC + 错误契约；实现细节明文不锁（写入 spec「非目标」，DEV 自主权）。
- **HITL 攒批签字**：多个 `qa_passed` 攒至一次终验会话批量签；签字记录绑定 commit 链（配合 ADR-0012 §3.3 基线 == 待推 sha）。
- 契约出具时间预算：单任务 spec ≤ 1 轮会话；超时降级为「先实现非契约面」，契约面挂 `waiting_user`。

## 3. 被否决方案

| 方案 | 否决理由 |
|---|---|
| 任意未通过均计熔断轮 | 契约歧义轮 DEV「修不动也不该修」，3 轮烧完停摆，真该第 1 轮就转 verdict |
| 契约锁实现细节 | ARCH 成串行瓶颈放大，DEV 自主权丧失，吞吐杀手（Q9 拷问点） |
| 逐任务 HITL 签字 | 人在场率是流水唯一节拍，逐任务等待把三 agent 速度废掉 |
| 弱断言当防作弊做（签名状态机等） | 威胁模型已收口「防呆不防恶」（ADR-0012），纯开销 |

## 4. 后果

- **正面**：熔断不再误伤契约/用例根因；QA 报告结论可信度对齐「落地质量」关切；并行任务有明文判据；HITL 从逐任务变攒批。
- **负面 / 缓解**：
  - 根因分类依赖 QA 判定力 → 缓解：分类不实可在复测轮由 DEV/ARCH 纠正重分类，只影响计数不影响流转。
  - mutation 抽查增加 QA 侧计算 → 缓解：仅对 diff 变异行抽样，非全量变异。
  - 基线 == 待推 sha 与攒批签字联用时，攒批期内新提交会作废旧签 → 缓解：签字绑定 commit 链，新增提交即触发增量复验，语义与 ADR-0012 §3.3 一致。
- **推翻条件**：QA 根因分类准确率长期不可靠（误分类率 > 30%）→ 改为机械启发式分类；mutation 抽查成本超 QA 预算 → 降级为按需触发。
