# ADR-0010 下游需求上下文回流机制

- 状态：accepted
- 日期：2026-10-27

## 上下文

下游项目（quant_skill 等）以本仓 TRIO 三角色机制运行。下游使用中会冒出本仓当前版本满足不了的新功能 / 新需求，只能回本仓开发，但需求上下文（场景、复现、期望、约束）留在下游。需要结构化回流通道，让下游产出「提示词信息」、用户带回本仓会话即开任务。

约束：`bin/**` 是门禁自保区（任何角色不可写，用户落盘）；`templates/*.md` 随 init-agent 自动注入下游（U1 升级覆盖）；下游 `docs/task/*/arch-*.md` 是 ARCH 既有写权；机制仓自身也以三角色开发；`feedback/` 7-格条目池是 quant_skill 使用反馈消化循环（TASK-005 B-1 有判据混用教训）。

## 候选方案

1. **模板卡**（七段 markdown 手填，住 `templates/`）—— 优点：零新工具、与 REPLY-CONVENTIONS 接力块同构、ARCH 可独立落盘；缺点：手填成本、格式靠填写人。
2. **脚本生成器**（`bin/trio-backflow.sh` 采版本戳 / 任务态生成提示词包）—— 优点：机械可信省手填；缺点：`bin/**` 需用户落盘、新增执行件 + 测试面 + 升级成本。
3. **skill 触发起草**（下游会话说「回流需求」，agent 现场起草）—— 优点：灵活、上下文抓得准；缺点：格式靠 agent 自律、无机械校验面。

## 决策

选定 **方案 1（模板卡）**。理由：回流是低频人参与流程，一张结构化卡即可闭环；工具化收益不足以支付门禁区落盘与测试面成本。

分支决策全集（grill `backflow-20261027` 逐题拍板）：

| 分支 | 决策 | 被否决方案及理由 |
|---|---|---|
| 产出形态 | 模板卡 `templates/backflow.template.md` | 脚本生成器（门禁区 + 测试面成本）；skill 起草（格式自律、无校验面）；模板先行、生成器记 backlog |
| 字段契约 | 七段全量：背景 / 触发场景（含复现）/ 现状与版本 / 期望行为 / 约束 / 建议验收 AC 草案 / 附件指针 | 极简三段（省填但往返追问更贵）；复现独立段（需求型常空段） |
| 传递载体 | 人肉复制粘贴（下游起草 → 用户粘进本仓会话） | scaffold 收件箱目录（多一套状态生命周期：谁清 / 谁归档 / 去重）；跨仓 git handoff（两仓耦合，为一个提示词包不值） |
| 版本戳 | 机械命令输出位 `git -C ~/projects/omp-trio-scaffold describe --tags` 原样粘贴 | 手填版本号（易忘易错，对账还得再问）；不带版本（丢「事发版本」溯源，需求可能已被新版修掉） |
| 与 feedback/ 池 | 独立双轨（回流卡 ≠ 7-格条目；交叉用【附件指针】绝对路径互链） | 复用 7-格条目（两套消化 / 归档 / 判据语义缠绕，B-1 类歧义裁决会重演） |
| 触发与起草 | 任意角色可触发；dev/qa 触发先收集上下文交 ARCH；起草恒归 ARCH；卡内路径一律绝对路径 | 仅 ARCH 可触发（浪费 dev/qa 一线发现）；任意角色起草（格式 / 完整度方差大）；任务收尾例行（上下文回忆失真） |
| 自豁免 | 约定级：模板头 + 契约 + 本 ADR 声明「机制仓自身禁用——自己不返回自己」 | 机械拦截（policy 是上游模板会波及下游，恰下游需要产卡，需「仅本仓生效」逻辑，复杂度不值）；init-agent 跳过注入（`bin/**` 门禁区，且回流模板源就住本仓 templates/，拦截面模糊） |
| 落地归属 | ARCH 全落（零执行件：模板 + 文档 + ADR + 契约） | 本仓 TRIO 全流程三棒（为一张模板开三棒属过度仪式）；用户手工（规格一致性无人把关） |

## 后果

- 正面：需求回流零基础设施；下游 ARCH 起草零越权（`arch-*-backflow-*.md` 命中既有写权）；模板随 init 注入自动覆盖全部下游；本仓改动面全在 ARCH / 公共写权内。
- 负面：手填成本与格式自律；无机械校验面；版本戳依赖填写人执行命令。缓解：模板自检清单；缺段卡由本仓 ARCH 补问（不算缺陷）。
- 推翻条件：
  1. 出现 ≥2 次回流卡缺段 / 格式事故 → 上机械校验或脚本生成器（届时开 DEV 车道，`bin/**` 走用户落盘通道）。
  2. 机制仓自身出现误用回流卡 → 升级 pre-commit 机械拦截（须先解决 policy 上游继承会波及下游的问题）。
  3. 回流频率高到人肉粘贴成为瓶颈 → 重议收件箱 / 跨仓通道。
