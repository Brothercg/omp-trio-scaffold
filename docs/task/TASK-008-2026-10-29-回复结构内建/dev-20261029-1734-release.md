## 7. 契约说明与偏差

| 项 | 说明 |
|---|---|
| AC-2c 调整 | 旧断言要求指针块落在文件最后 6 个非空行；spec v1 要求清单追加在指针段之后，二者不可同时成立。按 spec 真值调整该断言为「指针段与其后自查清单同处节末」，其余既有断言未动。新增 AC-5b 另行锁定清单六行逐字。 |
| 附录 B 逐字归一 | 合并 ① 先前落盘的口径句曾带反引号；本单按 spec §8 纯文本逐字对齐（去掉标记符，语义不变）。 |
| `.omp/trio` 副本 | spec 路由未列，但 `tests/trio-reply-conventions.test.mjs` AC-2b 与 `trio-gate-contract` AC-7 强制与 `profiles/` 逐字节相等，按历史同步 commit `0425e60` 同法一并同步。 |
