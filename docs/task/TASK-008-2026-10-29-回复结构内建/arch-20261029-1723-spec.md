## 4. 验收准则（Given-When-Then）

### AC-1 注入 byte-equal
- **Given** 干净目标目录（已存在且 `git init` 过——init 现有前置）
- **When** 运行 `bin/init-agent.sh <目标>`
- **Then** `<目标>/docs/REPLY-CONVENTIONS.md` 存在且与源逐字节相等（`cmp` exit 0 无输出）

### AC-2 幂等与升级覆盖
- **Given** 目标已 init，且注入件被改旧（或缺失）
- **When** 重跑 `bin/init-agent.sh <目标>`
- **Then** 注入件恢复为源内容（`cmp` exit 0）；内容未变化时输出「已是最新」且不重写（`cmp -s` 守卫语义）；连续两次 init 后 0 diff

### AC-3 三份简报增补
- **Given** `profiles/arch.rules.md`、`dev.rules.md`、`test.rules.md`
- **When** 逐份检查
- **Then** ① 「回复格式」节含附录 A 五行清单逐字，既有 `docs/REPLY-CONVENTIONS.md` 指针保留；② 三份熔断条在 `计 1 轮。` 后含 ADR-0013 口径句（逐字，附录 B）；③ `test.rules.md` 自检清单含根因分类项（附录 B）；④ 其余一字不动

### AC-4 selftest 检出项正/负两态
- **Given** 目标树经 init 部署
- **When** 运行 `bin/trio-selftest.sh`
- **Then** `[1/8]` 新项「回复规范已注入」绿
- **Given** 同目标树删除 `docs/REPLY-CONVENTIONS.md`
- **When** 重跑
- **Then** 该新项红并计入 FAIL，整体结果非全绿；其余检查行为不变

### AC-5 测试断言与零回归
- **Given** `tests/trio-reply-conventions.test.mjs` 扩展后
- **When** 运行全部 `tests/*.test.mjs`
- **Then** 新增断言至少覆盖：注入 byte-equal（临时目录实跑 init）、三份简报清单与指针存在、升级覆盖（改旧后重跑恢复）；全量 0 失败（原 405 项 + 新增）

## 5. 边界极值

| 边界 | 预期 |
|---|---|
| 目标 `docs/` 不存在 | init 既有 mkdir 循环创建；注入不报错 |
| 注入件缺失（首次部署） | `create_file` 新建（U1 语义） |
| 反复 init（≥2 次） | 幂等，0 diff |
| `selftest --fast` | `[1/8]` 不在 fast 跳过面，新检出项照常执行 |
| 源文档只改一处 | 下游重跑 init 即跟随（AC-2 推论） |

## 6. 错误契约与非功能

- init 对不可写目标沿用 `create_file` 既有错误语义（非 0 退出 + 明示路径）；selftest 检出缺失 → FAIL 计数 + 整体非全绿。
- 零新依赖；零回归（selftest 既有 26 项 + 10 套件 405 项）；不改 `docs/REPLY-CONVENTIONS.md` 本体；`policy.txt` 零改动。
- **非目标**：机械执法 hook（二期 C spike，omp 回复前挂点未核实，不硬造）；不改 REPLY-CONVENTIONS.md 内容。
