|---|---|
| 现象 | `cp -t src/ /tmp/f` 以 arch 身份执行被放行；写方向判反——最后一个位置参数是源，真正被覆盖的 src/ 未进写目标集 |

| 堆栈 | `.omp/hooks/pre/trio-guard.ts:694` `DEST_ONLY_WRITERS.has(command)` 分支:`positionalArgs(args)` 取最后元当目标;`positionalArgs` 无 `-t` 语义感知 |
| 同病变体 | `cp --target-directory=src X`、`install -t src X`、`ln -s -t src X`、`rsync --delete src/ X`(ALLOW，应 BLOCK) |

期望 / 实际 / 复现:期望 BLOCK + 命中写规则；实际 ALLOW(无任何写目标行)。复现:`env TRIO_ROLE=arch bun /tmp/qa7/probe-cpt.mjs`。
