## 1. 发布内容

本版本把 TASK-007 的门禁加固与流程契约落到可发布状态：

- **bash 执法面**：`judgeBash` 对写目标逐个走 allow + deny 全矩阵；
  realpath 归一后拦截 symlink 穿透与跨 worktree 出根。
- **发布证据绑定**：pre-push 要求报告基线 == 待推 sha，或 delta 仅文档
  白名单；guard / pre-commit / pre-push 三面 `# gate-version` 同判。
- **逃生舱审计**：pre-commit marker + post-commit `bypass(no-marker)` /
  `ok` 行；pre-push 放行前展示 bypass 审计。
- **BUG-1/2/3**：`-t` / `--target-directory` / `--delete` 写目标反转、
  gate-version 宽松解析、非法 `TRIO_ROLE` 静默放行三项全部修复。
- **流程契约**：spec 并行性/前置、board 熔断字段与根因列、report 根因
  机检、RUNBOOK 攒批签字与时间预算。
- **AC-13**：TASK-007 临时写通道已回收，`policy.txt` 恢复四条 `deny`。
