## 1. 实现摘要

按 ADR-0012 六项执法面加固 + ADR-0013 四项流程契约落地：bash 写目标改走
allow+deny 全矩阵；路径 realpath 归一（symlink 穿透、跨 worktree 出根拦截）；
pre-push 要求报告基线 == 待推 sha（文档 delta 白名单免复测）；三执法面
gate-version 自证；无身份写判定附醒目提示；pre-commit marker + post-commit
审计使 `--no-verify` 绕过可检出。流程侧补齐模板并行性/熔断字段、报告根因
分类机检（T11）、mutation 质量门与 RUNBOOK 流程契约。

## 8. 风险与注意事项

AC-2 契约示例写 `docs/task/T/l -> ../../src`，按相对路径实际指向 `docs/src`；
回归夹具采用 `../../../src` 才指向项目根 `src/`，实现按 realpath 语义判定，与链接深度无关。
