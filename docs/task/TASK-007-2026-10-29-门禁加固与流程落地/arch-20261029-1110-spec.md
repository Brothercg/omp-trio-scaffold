## 4. 接口签名

### 4.1 guard（`.omp/hooks/pre/trio-guard.ts`）
```text
normalizeFsTarget(raw: string, root: string) -> { relPath: string } | { escape: "worktree" } | { escape: "system" }
  // realpath 归一（symlink 解析后判定）；escape="worktree" → 拒绝（AC-3）；escape="system" → 不管辖（现状）

judgeBash(command: string, role: Role, snapshot: PolicySnapshot) -> Verdict
  // 与 write/edit 同语义：抽取写目标后走 decide() 全矩阵（allow+deny），不再只查 deny

checkGateVersion(declared: number, expected: number) -> Verdict
  // 不符 → fail-closed，reason=「执法件版本漂移」（AC-5）
```
- 无身份判定：`role == null` → 放行 + 返回 `warn: "无身份运行，门禁未生效"`（AC-6，每次写判定均提示）。

### 4.2 pre-commit / post-commit（用户落盘件）
```text
pre-commit:  校验通过后写 marker 文件 .git/trio-last-gate-ok = <commit 时间戳>
post-commit: 若本次提交无新 marker（--no-verify 绕过）→ 追加审计行
             .git/trio-audit.log: "<ISO时间> <commit-sha> bypass(no-marker)"
             有 marker → 追加 "ok" 行并清 marker
```
- `git commit --no-verify` 不抑制 post-commit（git 原生行为），审计因此可行；`core.hooksPath` 篡改属防恶出栈（ADR-0012 §2）。

### 4.3 pre-push（`templates/pre-push`）
```text
checkBaseline(reportBaseline: string, localSha: string, deltaPaths: string[]) -> Verdict
  // reportBaseline === localSha            → 继续其余门禁（AC-4）
  // 否则 deltaPaths ⊆ DOCS_WHITELIST       → 免复测放行（AC-4）
  // 否则                                   → 拒绝：「基线 ≠ 待推，delta 含代码路径」
DOCS_WHITELIST = ["docs/**", "*.md", "CHANGELOG.md"]   // 非代码路径白名单；*.md 按 policy glob 文法（* 含 /）匹配任意深度（verdict-1）
```
- 放行前输出 `.git/trio-audit.log` 中的 bypass 行（AC-7）。

### 4.4 mutation 质量门（`bin/trio-mutation-check.mjs`）
```text
bun bin/trio-mutation-check.mjs <diff-range> -- <test-cmd...>
  // 对 diff 变异行逐行抽变（算符/常量翻转），执行 test-cmd；
  // 存活变异（测试仍过）→ 退出码 1 + 存活清单（文件:行:变异）；全杀 → 0
```

## 5. 验收准则（Given-When-Then）

### AC-1 bash 全矩阵判定
- **Given** `TRIO_ROLE=arch`，policy 无 `src/**` 对 arch 的 allow
- **When** bash 执行 `cp /tmp/f src/x.py`
- **Then** 拒绝并明示命中（回归基线：当前版本放行此命令）
- **Given** `TRIO_ROLE=qa`，policy `allow qa tests/**`
- **When** bash 执行 `tee tests/y.py`
- **Then** 允许

### AC-2 symlink 拒穿透
- **Given** `docs/task/T/l` 是指向 `../../src` 的符号链接
- **When** write 工具写 `docs/task/T/l/evil.py`（或 bash `cp f docs/task/T/l/evil.py`）
- **Then** 拒绝 + 明示「symlink 穿透」；词法归 docs/ 不再放行

### AC-3 跨 worktree 出根拦截
- **Given** 同仓另一 worktree 根 `W2`，当前会话 `TRIO_ROLE` 已设
- **When** 写 `W2/src/x.py`（绝对路径）
- **Then** 拒绝 + 提示「跨 worktree 写入不支持」
- **Given** 目标为 `/tmp/x.py`（非任何 worktree 根内）
- **When** 写入
- **Then** 放行（不受管辖，维持现状——本条款「出根」收窄为「其他 worktree 根内」）

### AC-4 基线 == 待推
- **Given** 报告基线 `B` == 待推 `local_sha S`
- **When** pre-push
- **Then** 基线项通过
- **Given** `B != S` 且 `B..S` delta 仅含 `DOCS_WHITELIST` 路径（`*.md` 任意深度，verdict-1）
- **When** pre-push
- **Then** 免复测放行
- **Given** `B != S` 且 delta 含任意代码路径
- **When** pre-push
- **Then** 拒绝 + 明示「基线 ≠ 待推，需 QA 重跑」

### AC-5 执法件版本自证
- **Given** `policy.txt` 含 `# gate-version: 2`，guard/pre-commit/pre-push 内嵌 `EXPECTED=2`
- **When** 任一执法面启动判定
- **Then** 正常执行
- **Given** 任一执法件内嵌版本 ≠ 声明版本（或声明缺失）
- **When** 启动判定
- **Then** fail-closed + 明示「执法件版本漂移」

### AC-6 无身份醒目提示
- **Given** `TRIO_ROLE` 未设置
- **When** write/edit/bash 写判定触发
- **Then** 放行，且**每次**附醒目提示「无身份运行，门禁未生效」（不得静默）
- **Given** `trio-install.sh --check` 类自检纳入 RUNBOOK 日常清单
- **When** QA 核验
- **Then** RUNBOOK 含该步骤

### AC-7 逃生舱绕过审计
- **Given** 任意角色执行 `git commit --no-verify`
- **When** post-commit 触发
- **Then** `.git/trio-audit.log` 追加 `bypass(no-marker)` 行（含 sha 与时间）
- **Given** 正常提交（pre-commit 写 marker）
- **When** post-commit 触发
- **Then** 追加 `ok` 行，无 bypass 行
- **Given** 存在 bypass 行
- **When** pre-push 执行
- **Then** 放行前输出全部 bypass 行

### AC-8 ARCH 产出模板义务（Q3/Q9）
- **Given** `templates/spec.template.md`
- **When** QA 核验模板
- **Then** 含「可并行性 / 前置条件」段与「实现细节不锁（写入非目标）」提示
- **Given** ARCH 输出多任务的回复分配块
- **When** 用户读取
- **Then** 每任务标注可并行性与前置条件

### AC-9 根因分类机检（Q8）
- **Given** QA 报告结果表中结论为「未通过」的行
- **When** `bun bin/trio-check-report.mjs <report>`
- **Then** 说明列缺 `[根因:实现]`/`[根因:契约]`/`[根因:用例]`/`[根因:环境]` 之一 → 违规（非 0 退出）
- **Given** 标签齐备的报告
- **When** 校验
- **Then** 通过

### AC-10 熔断字段与口径（Q8）
- **Given** `templates/board.template.md` 含「熔断计数」字段（实现轮 N/3）与根因分类列
- **When** QA 核验
- **Then** 字段存在；`docs/RUNBOOK.md` 熔断段明文「仅实现缺陷轮计数，契约/用例/环境轮 1 轮内转 verdict，不计数」

### AC-11 HITL 攒批与时间预算（Q9）
- **Given** `docs/RUNBOOK.md`
- **When** QA 核验
- **Then** 含「攒批签字（签字绑 commit 链）」与「单任务 spec ≤ 1 轮会话，超时降级先做非契约面」两段

### AC-12 mutation 质量门（Q7）
- **Given** 一段含可变异行的 diff 与测试命令，测试对某变异行不敏感
- **When** `bun bin/trio-mutation-check.mjs <range> -- <test-cmd>`
- **Then** 退出码 1 + 存活清单（含文件:行）
- **Given** 测试杀死全部变异
- **When** 同上
- **Then** 退出码 0
- **Given** 空 diff / 测试命令不存在 / 超时（单变异预算 30s）
- **When** 同上
- **Then** 退出码 2 + 明示原因（不静默计为通过）

### AC-13 窗口回收核验
- **Given** TASK-006 与 TASK-007 均 `user_signed`
- **When** 用户删除 policy 通道块并恢复 `deny *` 原文后，QA 复核
- **Then** policy.txt 恢复目录级 `deny *`（无 `allow arch .omp/hooks/**` 残留）；审计记录回收动作记看板

## 6. 边界与极值

| 场景 | 期望 |
|---|---|
| symlink 链（多级/环） | realpath 解析后判定；环 → 拒绝 + 明示 |
| 相对路径 `../` 逃逸 | 归一后落入 worktree 判定或 system 判定，不复归词法目录 |
| 路径含空格/引号 | bash 分词保持既有引号处理；写目标抽取不回归 |
| `gate-version` 行缺失 | fail-closed（视为漂移），明示缺失 |
| delta 为空（基线==sha） | 基线项通过，无需白名单判定 |
| audit.log 不存在 | pre-push 视为无 bypass 行，不报错 |
| mutation 目标行为不可变异（空 diff） | 退出码 2，不计「全杀」 |

## 7. 错误契约

| 错误 | 触发 | 响应 |
|---|---|---|
| 版本漂移 | AC-5 | fail-closed + 明示（guard/pre-commit/pre-push 三面同判，承 ADR-0011） |
| symlink 穿透 | AC-2 | 拒绝 + 明示 |
| 跨 worktree 写 | AC-3 | 拒绝 + 提示 |
| 基线 ≠ 待推 | AC-4 | 拒绝 + 明示 delta 含代码 |
| 根因分类缺失 | AC-9 | check-report 违规（非 0） |
| mutation 工具异常 | AC-12 | 退出码 2 + 原因 |

## 8. 非功能约束

- guard 判定预算沿用 ADR-0011（< 5ms p95）；post-commit 开销 < 50ms；mutation 单变异预算 30s、抽样上限 20 变异/diff。
- 兼容：policy DSL 语法与 deny 优先判定语义不变（gate-version 为注释行，不进语法）。
- 可观测：全部拦截文案含快照标识（TASK-006）+ 本任务新增原因明示；审计日志仅追加。

## 9. 非目标

- **不防恶意绕过**（ADR-0012 §2）：`python3 -c "open(...)"` 等解释器内部写、`core.hooksPath` 篡改、`--no-verify` 本体禁止——均为防恶出栈；本任务只保证绕过**可检出**（AC-7）。
- 不做多 worktree 全 roots 管辖（ADR-0012 §3.4 否决项）。
- 不改 policy DSL、不加 deny 例外/到期语义（ADR-0003 方案 4 否决项）。

## 10. 分工

- **用户**（根信任落盘，唯一可为）：① policy.txt 通道 diff + `# gate-version: 1` 行（附录 A）② `templates/pre-commit` + 部署件的 marker 改动 ③ 运行 `bin/init-agent.sh` 部署 post-commit / 刷新 pre-push ④ 终验后回收窗口（AC-13）。
- **DEV**：切片 A/C 补丁内容起草（`dev-*.md` 内联 diff + 真实自测输出），含 guard/pre-push/post-commit 模板/check-report/mutation 工具/selftest。
- **ARCH**：经窗口代施 DEV 补丁落盘（git 历史 + dev-*.md 双溯源）；切片 B（模板 + RUNBOOK）端到端直改；契约维护。
- **QA**：AC-1..AC-13 对抗用例（`tests/**`，无前置可先行设计）；mutation 门的用例敏感性验证；回收核验（AC-13）。
