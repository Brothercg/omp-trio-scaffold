## 1. 发布内容

1. **安装布局无关化 ⑩**
   - `bin/init-agent.sh` 新增 `--dry-run`：零写入预览，输出
     `将创建` / `将覆盖` / `将跳过` / `将保留` 四类计划行与
     `干跑：…（零写入）` 汇总。
   - 新增 `--layout auto|bin|tooling`：`auto` 按目标 `tooling/bin`
     是否存在判定；`bin` / `tooling` 显式覆盖；非法值/缺值 exit 2。
   - tooling 布局落点：`tooling/bin/`、`tooling/tests/`、`tooling/hooks/`；
     `.git/hooks/*` 对模板做一次 `bin/trio-` → `tooling/bin/trio-` 替换，
     `trio-policy-eval.mjs` 的 guard 导入同步适配。
   - 下游领先集合 `AHEAD = {docs/REPLY-CONVENTIONS.md, .omp/trio/templates/board.template.md}`
     默认保留并计入跳过，`--force` 才覆盖；`policy.txt` 不受 `--force` 影响。
   - `bin/trio-align.sh` / `bin/trio-selftest.sh` 按 `.omp/trio/policy.txt`
     向上两级自定位仓库根，兼容 bin / tooling 两种安装位置。
2. **报告矩阵机检 T12 ⑪**
   - `bin/trio-check-report.mjs` 新增 `checkMatrix`（M1–M10）并挂入
     `checkText`：覆盖矩阵段存在/唯一、表头两列、AC 编号合法且不重复、
     用例引用可解析、SKIP 行「理由+挂起」成对、空矩阵拒绝。
3. **测试与归档**
   - 新增 `tests/trio-init-layout.test.mjs`（15 项）。
   - `trio-check-report` 增至 67 项（T12 正例 1 + 反例 13）。
   - pre-push / reply-conventions 夹具补矩阵段并适配领先保留语义。
   - CHANGELOG `## v0.9.0`、TASK-009 spec / ADR-0015 / 交付说明 / QA 双件归档。

## 6. 已知边缘与说明

- `--layout auto` 以目标是否已有 `tooling/bin` 判定；下游若两套并存，
  需显式 `--layout bin|tooling`。
- 领先文件默认保留，只有 `--force` 覆盖；`policy.txt` 永不被 `--force`
  覆盖，差异保留。
- T12 的矩阵行结论按引用用例解析；若表含结论列则 M9 生效。
- 本版本不改写 `v0.7.0` / `v0.8.0` 的 CHANGELOG、发布说明或 tag。
