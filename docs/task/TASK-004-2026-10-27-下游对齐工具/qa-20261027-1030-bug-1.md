## 1. 现象

在脚手架本仓干净 HEAD（`git archive abba014 | tar -x` 到 /tmp）上运行
`bash bin/trio-align.sh --check .`，退出码 1 而非 0：

```text
task-name | docs/task/TRIO-SELFTEST | - | 需重命名为 TASK-<NNN>-<YYYY-MM-DD>-<slug>
```

`--check` 还列出 `missing-dir | src/`（src/ 下无 tracked 文件时）——脏工作树上
该差异被未提交的删除掩盖（DEV 自测时 measured `aligned` 属脏树态）。

## 2. 复现

```bash
# /tmp/task004-qa/probe-ac9-head.sh
S=/home/cg/projects/omp-trio-scaffold
H=/tmp/qa4-head; rm -rf $H; mkdir -p $H
git -C $S archive HEAD | tar -x -C $H
cd $H && git init -q && bash bin/trio-align.sh --check .
# → exit 1, task-name | docs/task/TRIO-SELFTEST
```

稳定复现，无网络/时钟依赖。
