## 8. 风险与注意事项

- 本仓库**已安装的** `.git/hooks/pre-push` 仍是旧版（不属于 git 跟踪文件）；
  本次只交付 `templates/pre-push` 与 init 部署逻辑。发布 TASK-002 前需由
  用户/ARCH 用 `bin/init-agent.sh --force` 或手动安装新模板，否则实际 push
  仍走旧判定。
- `pre-push` 现在要求看板有 `qa_report` 字段；旧任务看板若无此字段，dev 推送会被拒（符合 AC-4，迁移时需补字段）。
- `release_gate` 字段必须留在标识段（`| 字段 | 值 |` 表格），`field_value` 只解析该表。
- guard 是尽力而为层：`cp tests/x /tmp` 视为读 tests、写 /tmp，不拦截；权威判定仍由 pre-commit / pre-push 承担。
