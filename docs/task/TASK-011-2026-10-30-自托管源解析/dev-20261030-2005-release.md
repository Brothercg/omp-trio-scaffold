## 1. 实现摘要

`init-agent.sh` 增加逐载荷源侧解析：hooks / 工具 / 测试 / 文档模板 / 角色简报分别按
「上游树 → 自托管树」取首个存在项，自托管（脚本位于 `<root>/tooling/bin/`）不再误读
`<root>/templates/<hook>`。缺源改为逐件 `失败 …：源缺失 …` 并继续，hooks 三件全缺才
preflight 中止；`--dry-run` 与实跑共用解析，缺源时干跑同样 fail-closed。hook 产物替换
对已含 `tooling/` 前缀的 token 加保护，重复应用不再产生 `tooling/tooling/`。

## 6. 边界与风险

- 源候选按 S1 顺序「上游树 → 自托管树」逐载荷独立选择；混合源可用。
- 源缺失在计划/执行前判定，不再依赖 `sed`/`install` 的失败退出；干跑与实跑同一判定。
- hook 替换使用占位保护已含 `tooling/bin/trio-` 的 token；对普通路径仍允许 `/` 前导，
  以覆盖 `${PROJECT_ROOT}/bin/trio-…` 形态。
- 自托管 `ROOT == TARGET` 时源/目标同路径，`cmp -s` 走「已是最新」，不会自写。
- 下游重跑原始命令、19 条 SKIP 与 C-13 关行仍待 v0.9.2 发布后重装。
