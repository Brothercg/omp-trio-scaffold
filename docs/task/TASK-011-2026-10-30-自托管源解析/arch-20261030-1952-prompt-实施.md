### 2. preflight 与缺源语义（S2）

- hooks 三件候选全缺 → exit 1，stderr `脚手架不完整：未找到 hooks 源（候选：<A> / <B>）`。
- 其余载荷：某件候选全缺 → 打印 `失败 <rel>：源缺失 <候选列表>`，`FAILED++`，继续处理其余件；
  不得在 `sed` / `install` 处整步中断。

### 3. 干跑源校验（S3）

计划行打印**前**先解析源；源缺失时只打印失败行，不打印 `将创建/将覆盖`。
dry-run 结束：`FAILED>0` → exit 1；否则 exit 0 + 汇总（含「零写入」）。干跑与实跑共用同一解析/判定函数。

### 4. 替换幂等（S4）

`create_hook` 的替换改为左边界感知：只替换未处于 `tooling/` 前缀下的 `bin/trio-`
（前导字符不得为 `/` `字母` `数字` `_` `.` `-`）。校验：对已含 `tooling/bin/trio-` 的源，产物与源
逐字节相同，不出现 `tooling/tooling/`。其余（`plan` / `--force` / 汇总）逻辑不变。
