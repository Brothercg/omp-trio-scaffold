## 1. 任务目标

下游项目（quant_skill 等）使用本仓机制期间冒出的、本仓当前版本满足不了的新功能 / 新需求，通过**回流卡**（结构化提示词）带回本仓会话立项开发；上下文不靠人脑搬运。

## 2. 契约：回流卡（backflow card）

### 2.1 命名与落位（下游侧）

- 文件名：`arch-<YYYYMMDD>-<HHMM>-backflow-<主题>.md`（命中下游 `docs/task/*/arch-*.md` 既有 ARCH 写权，起草零越权）。
- 落位：`docs/task/<当前任务>/`；无进行中任务时 `docs/task/backflow-<YYYYMMDD>-<主题>/`。
- **一卡一需求**：多个需求拆多张卡。

### 2.2 七段 schema（段名与顺序固定，MUST 齐备）

| 段 | MUST 内容 | 极值规则 |
|---|---|---|
| 【背景】 | 哪个下游项目、什么场景冒出 | ≥1 句 |
| 【触发场景】 | 操作路径 / 复现步骤 | 新能力型写「无复现，属新能力」 |
| 【现状与版本】 | 当前行为 + 版本命令输出 | 版本输出 = `git -C ~/projects/omp-trio-scaffold describe --tags` 原样粘贴（本工作区约定路径，别处以机制仓实际绝对路径为准） |
| 【期望行为】 | 可判定表述 | MUST NOT 用「更好 / 更合理」类不可判定词 |
| 【约束】 | 不可推翻约束 | 无则写「无」 |
| 【建议验收 AC 草案】 | Given-When-Then 条目 | ≥1 条；可不完善，机制仓 ARCH 修订 |
| 【附件指针】 | 相关文件**绝对路径** | 无则写「无」；MUST NOT 相对路径 |

### 2.3 起草与传递流程

1. 任意角色触发（习惯语：「回流需求」）。
2. dev / qa 触发 → 先收集上下文 → 交 ARCH；**起草恒归 ARCH**（基于下游项目整体情况）。
3. 卡完成后，用户复制卡内正文粘贴进本仓会话 → 即开任务（人肉传递，无收件箱、无跨仓 git）。

### 2.4 自豁免

机制仓自身开发**禁用**回流卡（自己不返回自己）。约定级：模板头 + 本契约 + ADR-0010 三方声明；升级机械拦截的推翻条件见 ADR-0010。

### 2.5 与 feedback/ 池双轨

回流卡是独立产物类型：不入 `feedback/` 7-格条目池，feedback 条目不作回流卡。确有交叉时在【附件指针】给绝对路径互链。

## 4. 验收准则（Given-When-Then）

### AC-1 模板注入
- **Given** 未初始化项目 P（本机）
- **When** 执行 `trio-init`（init-agent.sh）
- **Then** `P/.omp/trio/templates/backflow.template.md` 存在，且与 `templates/backflow.template.md` 逐字节相等

### AC-2 卡片完备
- **Given** 一张回流卡
- **When** 对照 §2.2 自检清单
- **Then** 七段齐备；版本输出非空（或明示「版本未知」+ 原因）；【附件指针】全为绝对路径或「无」

### AC-3 自豁免
- **Given** 机制仓自身
- **When** 枚举 `docs/task/**`
- **Then** 无 `arch-*-backflow-*.md`（本仓不产回流卡）

### AC-4 双轨独立
- **Given** 回流卡与 feedback 池
- **When** 枚举两侧产物
- **Then** `feedback/` 内无 backflow 文件；回流卡不落 `feedback/`

### AC-5 起草归属
- **Given** dev / qa 触发回流
- **When** 卡产出
- **Then** 起草人 = ARCH（dev / qa 仅收集上下文）

## 5. 边界极值

| 场景 | 期望 |
|---|---|
| 附件文件本仓不可访问（相对路径 / 跨机器） | 【附件指针】只收绝对路径；确实不可访问时把内容摘录进卡内 |
| 新能力无复现 | 【触发场景】写「无复现，属新能力」 |
| 多需求同时冒出 | 一卡一需求，拆卡 |
| 版本命令跑不了（机制仓不在约定路径） | 改用机制仓实际绝对路径；两处都跑不了 → 写「版本未知」+ 原因 |
| 卡缺段 | 起草自检清单拦截；本仓会话收到缺段卡 → ARCH 补问后立项（不算缺陷） |

## 6. 非功能约束

| 维度 | 要求 | 验证 |
|---|---|---|
| 零执行件 | 不动 `bin/**`（门禁自保区） | diff 审 |
| 零新依赖 | 模板 + 文档，无三方依赖 | diff 审 |
| 注入语义 | 随 init-agent U1 升级覆盖 | AC-1 |
| 双轨不混 | 与 feedback/ 池零交集 | AC-4 |

## 7. 范围外

- 脚本生成器（`bin/trio-backflow.sh`）——记入 backlog；真实使用反馈证明手填痛再议（推翻条件见 ADR-0010）。
- 两仓 git 自动同步 / 收件箱目录 / 机械校验面。
- `feedback/` 消化循环（§8）改动。
