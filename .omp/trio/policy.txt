# TRIO 写策略 —— 单一真值源 (single source of truth)
#
# 本文件被两处同时消费，必须保持二者语义一致：
#   1. .omp/hooks/pre/trio-guard.ts   —— 进程内写前拦截（实时）
#   2. templates/pre-commit            —— 提交前兜底（git）
#
# ── 语法 ──────────────────────────────────────────────────────────────────
#   allow <role> <glob>       该角色允许写入该路径
#   deny  <role> <glob>       该角色禁止写入该路径
#   '#' 开头为注释；空白行忽略。
#
# ── 匹配语义 ──────────────────────────────────────────────────────────────
#   路径相对于项目根目录（POSIX 分隔符）。
#   '*' 匹配任意字符（含 '/'）；'**' 等价于 '*'。
#   例：'docs/specs/**' 匹配 docs/specs/ 下任意深度的文件。
#       'requirements*.txt' 匹配 requirements.txt、requirements-dev.txt。
#
# ── 判定语义（deny 优先）──────────────────────────────────────────────────
#   1. 收集 role 匹配当前角色的全部规则（role 为 '*' 即适用于所有角色）。
#   2. 任一 deny 命中        → 拒绝。
#   3. 否则任一 allow 命中   → 允许。
#   4. 否则                  → 拒绝（fail-closed）。
#
#   角色取值：pm / dev / qa。
#   未设置 TRIO_ROLE 的会话不执行本策略（见 hook 与 pre-commit 的说明）。
#
# ── 作用域 ────────────────────────────────────────────────────────────────
#   本策略只管辖项目根目录以内的路径。xd:// 设备传输、local:// 会话草稿、
#   项目根目录以外的绝对路径不受管辖（它们不属于三方契约目录）。
